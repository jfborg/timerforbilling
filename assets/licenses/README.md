# Asset licenses

Per the IP guardrails, every stationery design, seal, illustration, sound, animation and font
used in the app must be either original work or under a permissive licence (MIT, Apache-2.0,
BSD, OFL for fonts), with the licence file committed here, one file per asset or asset pack.

Nothing has landed yet: Phase 0 ships no stationery, seals, sounds or custom fonts. The first
real assets arrive in Phase 2 (three visual direction mocks) and Phase 9's visual identity
work. When an asset is added:

1. Commit the licence text (or a link plus the licence name if the source has no separate
   licence file) alongside the asset, named `<asset-name>.LICENSE.txt`.
2. If the asset is original work made for this project, note that here instead, for example
   `wax-seal-icon.png: original artwork, owner holds full rights`.
3. Never commit an asset whose licence is unknown or that forbids commercial use.
